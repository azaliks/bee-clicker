# FriendCheck — тест на дружбу

Небольшой адаптивный сайт-конструктор тестов на дружбу.

## Возможности
- Готовая подборка вопросов для быстрого старта.
- Добавление собственных вопросов и вариантов ответов.
- Выбор правильного ответа для каждого вопроса.
- Генерация ссылки, которой можно поделиться с друзьями.
- Прохождение теста, подсчёт результата и разбор ответов.
- Автосохранение черновика в браузере через localStorage.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку `friendship-test` как статический сайт.

Тест передаётся в ссылке, поэтому отдельный сервер или база данных не нужны.
